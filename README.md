## Project Objective

The objective of this mini-project is to develop a simple Birthday Guess Calculator using PHP. The system takes input from the user and uses simple calculations and conditions to guess the user's birthday.

## Features

* Simple birthday guessing system
* User input through HTML form
* Uses PHP calculations
* Uses PHP conditions
* Simple and attractive web interface
* Easy-to-use design
* Birthday result displayed on the webpage
* CSS styling for better appearance
* No database required

## Algorithm / Flowchart

### Algorithm

1. Start the application.
2. Display the Birthday Guess Calculator form.
3. Take the required input from the user.
4. Process the input using PHP.
5. Perform the required calculations.
6. Apply conditions to calculate the possible birthday.
7. Display the guessed birthday.
8. Allow the user to try again.
9. Stop.

## Steps to Run

### Using XAMPP

1. Install and open XAMPP.
2. Start Apache.
3. Copy the `dimple` project folder into:

```text
C:\xampp\htdocs\
```

4. Open a web browser.
5. Visit:

```text
http://localhost/dimple/
```

6. Enter the required information.
7. Click the button to calculate the birthday.
8. The guessed birthday will be displayed on the screen.

### Using PHP's Built-in Server

Open the project folder in Command Prompt/Terminal and run:

```text
php -S localhost:8000
```

Then open:

```text
http://localhost:8000
```
